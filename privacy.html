プライバシー

このサイトは静的なGitHub Pagesサイトです。サイト独自のユーザー登録、決済、問い合わせフォームは設けていません。

アクセス解析

サイトの利用状況と表示品質を改善するため、Google Tag Manager、Google Analytics 4およびMicrosoft Clarityを使用する場合があります。ページ閲覧、参照元、端末情報、プロジェクトや外部リンクのクリックなどがCookieその他の識別子とともに処理される場合があります。

GTM、GA4、Clarityは全ページ共通スクリプトからそれぞれ1回だけ初期化します。公開中のGTMコンテナにはGA4とClarityを重複登録していません。

主要イベント

プロジェクト、GitHub、LinkedIn、商用サービス、問い合わせ、デモへのリンク操作を、サイト改善のためのイベントとして記録する場合があります。入力フォームの内容やメールアドレスはこのサイトから送信しません。

外部サービスと通信

GitHub Public APIへアクセスして公開リポジトリ情報を表示します。Google、Microsoft、GitHubおよび外部リンク先では各サービスのプライバシーポリシーが適用されます。

Search Console

Google Search Consoleは検索表示状況とクロール状態の確認に使用します。Search Console自体が訪問者向けの追加計測スクリプトを配信するものではありません。

お問い合わせ

商用相談はSLEEP LATE LABの問い合わせページで受け付けます。送信情報の取り扱いはリンク先の方針をご確認ください。
