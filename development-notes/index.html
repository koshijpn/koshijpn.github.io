I18N / STATE

Locale resolver design

Problem
保存値、URL、browser、regionの順序が分散し、本文とlocaleが一致しない可能性。
Investigation
非同期region resolverが初期描画後に状態を上書きする経路を確認。
Solution
明示選択 → URL → stored → browser → region → defaultという責務を一つのresolverへ集約。
Evidence
ONII Media 16/16 tests PASS、BorderLens pre-flight PASS。
Lesson
localeは表示コンポーネントごとに推測せず、metadata生成前に一度決定する。

CI/CD / HUMAN APPROVAL

Notion approval pipeline

Problem
build対象とPublished更新対象の同一性、および本番到達の保証が不足。
Investigation
Pages deployment 404と、deploy後のApproved全件再取得を分離して確認。
Solution
Approved 1件のpage IDとslugを固定し、Production HTTP確認後だけ同一IDを更新。
Evidence
HOKKAI TRACE 15/15 tests PASS。Productionは404のためWIP。
Lesson
CI成功ではなくProduction表示と外部状態更新までをrelease transactionとして設計する。
