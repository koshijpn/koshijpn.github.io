# koshijpn.github.io AdSense policy

AdSense, Auto Ads and manual units are disabled. Publisher/ad unit IDs are not
known and `/ads.txt` must remain absent until AdSense supplies the exact record.

Developer credibility and Project/GitHub/Live Demo actions take priority.
Home, project lists/details, evidence, code blocks, demos, GitHub links, Contact,
navigation and first view are excluded. Only substantial Technical Articles,
Engineering Notes and Tutorials may use one in-content unit initially.

Activation requires human approval of the public `ca-pub-...`, ad unit ID,
AdSense-provided ads.txt line, CMP/Consent Mode, CSP origins and Auto Ads route
exclusions. Compare project engagement against article revenue before expansion.
